# Purchase Order Revision Number

This module updates the revision number of the purchase orders which have been confirmed and being revised.

## Feature
  - ✅ Purchase order Revision Number on canceling confirmed purchase order
  - ✅ Old revisions are archived as separate orders, browsable via smart buttons
