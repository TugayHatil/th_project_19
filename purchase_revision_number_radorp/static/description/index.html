Odoo18 Purchase revision Number

Key Highlights

Purchase order Revision Number on canceling confirmed purchase order

When a confirmed Purchase Order is cancelled, users have the option to revise the PO with an updated revision number. This helps in tracking changes after confirmation. If the Purchase Order is not confirmed, the default "Reset to Draft" button is available instead, which does not update the revision number.

What happens to the revision number when a confirmed Purchase Order is cancelled ?

When a confirmed Purchase Order is cancelled, the system allows the user to revise it, and the revision number is incremented.

Does cancelling an unconfirmed Purchase Order affect the revision number ?

No, cancelling or resetting an unconfirmed Purchase Order does not update the revision number.

Can I manually change the revision number of a Purchase Order ?

Typically, the revision number is system-controlled and updated automatically during the revise action for confirmed orders.

Why doesn't the revision number change when I reset a draft PO ?

Because the PO was never confirmed, resetting it to draft is considered a regular modification and doesn't warrant a new revision.

How do I install the module after purchase ?

Extract the ZIP file and copy the module folder to your Odoo addons directory.

Which Odoo versions are supported ?

This module is available for Odoo 16,17,18 versions.
