# Purchase Dynamic Approval

Satınalma siparişinin toplam tutarına göre hangi kullanıcı grubunun
onaylayacağını belirleyen barem bazlı onay akışı. Standart
"Onay Bekliyor" durumu üzerinden çalışır; barem başına opsiyonel
vekil onaycı, zorunlu red nedeni, onay geçmişi ve tutar
değişikliğinde yeniden değerlendirme içerir.

Baremler Satınalma > Yapılandırma > Onay Baremleri altında
yönetilir. Örnek baremler pasif gelir.

Bağımlılık: `purchase`
